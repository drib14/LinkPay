# LinkPay ☕
Modern Coffee-Themed Mobile Banking App & Digital Wallet for the Philippines.

Built with **React Native (Expo SDK 52) + Express.js + JSON Storage**.

## Features
- ☕ Warm Coffee UI inspired by GCash / Maya
- 💳 Interactive Virtual ATM Card with EMV chip & Lock/Unlock toggle
- 🔐 Secure PIN authentication with 3-attempt lockout
- 💰 Cash Deposit (₱100 - ₱100,000) & Withdrawal (₱100 - ₱20,000, ₱50k daily limit)
- 💸 Money Transfer with ₱15 fee & atomic updates
- 📊 Transaction History with filtering & pagination
- 📈 System-Wide Banking Reports & Analytics
- 🚫 Zero-balance Account Deactivation
